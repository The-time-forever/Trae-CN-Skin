# Firefly reference material

The illustration was generated locally with an AI image model on 2026-10-24 from a text prompt, then saved as JPEG. It is an original rendering inspired by the visual language of Honkai: Star Rail's Firefly; no game asset, official artwork, screenshot or third-party image was copied or modified. The character and related intellectual property remain with miHoYo / HoYoverse, and this material claims no rights over them.

Redistribution of this illustration is limited to use alongside this project's skins; review the character rights before publishing it in other contexts. The `background.jpg` file is shared by both configs, and the dark and light configs express the same crop and image settings with mode-specific colors.

To activate this material, replace the current files in `themes/` with `background.jpg`, `dark.json` and `light.json`, then run `start.bat`. The previous material stays available under `materials/`.
