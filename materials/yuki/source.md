# YUKI reference material

The image is the file supplied by the project user as personal local reference material, identical to `materials/subaru/background.jpg`. Its original author, original URL and redistribution permission have not been established. No public redistribution right is assumed. See [the source record](../../docs/SOURCES.md).

The dark and light configs apply a high-key monochrome look to the same unmodified `background.jpg`: cool gray tokens, a right-anchored portrait crop centred on the face, and lower opacity on task pages so text stays readable. To activate this material, replace the previous active files in `themes/` with `background.jpg`, `dark.json` and `light.json`, then run `start.bat`.
