# Moonlit reference material

A custom material for Task2. The image `background.png` was supplied by the
project user as personal local reference material. Its original author, original
URL and redistribution permission have not been established, so no public
redistribution right is assumed. See [the source record](../../docs/SOURCES.md).

The dark config uses a dusk-gold accent (`#d9a463`) with a near-black graphite
surface; the light config keeps the existing light palette. Both use the same
unmodified `background.png`, with `focusX 88`, `focusY 38` and `imageWidth 56`
so the moon stays inside the visible right panel.

To activate this material, copy `background.png`, `dark.json` and `light.json`
into `themes/`, replacing the previous active files, then run `start.bat`.
