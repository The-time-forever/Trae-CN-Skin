# CLANNAD School Festival material

The image `background.webp` was supplied by the contributor from their personal collection as reference material for the `clannad-school-festival` skin (CLANNAD anime club members group illustration). Its original author and studio (Key / VisualArt's and the CLANNAD anime production) retain all rights. No redistribution license or permission evidence is established for this submission; it is treated as personal local reference material and no public redistribution right is assumed. See [the source record](../../docs/SOURCES.md).

The image pixels are unchanged; the configs only crop, fade and mask it with CSS. The dark and light configs both reference the same unmodified `background.webp`. To activate this material, copy `background.webp`, `dark.json` and `light.json` into `themes/`, replacing the previous active files, then run `start.bat`.
